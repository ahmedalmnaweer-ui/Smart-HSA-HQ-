# 🏗️ نظام التكاليف الذكي - Smart HSA Cost Analyzer

**نظام متخصص لتحليل وتقدير تكاليف المشاريع الإنشائية والهندسية**

---

## 📋 نبذة عن المشروع

نظام **Smart HSA Cost Analyzer** هو تطبيق ويب حديث مبني بـ **Streamlit** ويوفر حلاً متكاملاً لـ:

- ✅ **استيراد وتحليل بيانات المشاريع** من ملفات Excel (BOQ، جداول كميات)
- ✅ **حساب التكاليف التقديرية** بناءً على المواد والعمالة والموارد
- ✅ **إدارة قاعدة بيانات المواد والمواصفات**
- ✅ **مقارنة عطاءات المقاولين**
- ✅ **رسوم بيانية تفاعلية** لتحليل التكاليف
- ✅ **تقارير شاملة وتحليلات متقدمة**

---

## 🚀 المميزات الرئيسية

### 1. **الرئيسية** 🏠
- عرض إحصائيات سريعة (البنود المحفوظة، المواد، الموارد البشرية)
- استيراد ملفات Excel بشكل سهل وسريع
- معالجة تلقائية للبيانات

### 2. **التكلفة التقديرية** 📊
- عرض البنود المستوردة مع إمكانية الاختيار
- حساب التكاليف ديناميكياً
- تقسيم التكاليف (مواد، عمالة، ربح)
- رسوم بيانية توزيع التكاليف

### 3. **المواد والمواصفات** 🏭
- إدارة شاملة لقاعدة بيانات المواد
- إضافة مواد جديدة وتحديث الأسعار
- تتبع تطور الأسعار عبر الزمن
- مقارنة الموارد المختلفة

### 4. **عروض الأسعار** ⚖️
- مقارنة عطاءات المقاولين
- تحليل الفروقات والأسعار التنافسية
- رسوم بيانية للمقارنة

### 5. **التحليلات والتقارير** 📈
- مؤشرات أسعار المواد
- توزيع المقاولين حسب السعر
- تقارير شاملة وقابلة للتصدير

## 💻 التثبيت والتشغيل

### **المتطلبات الأساسية**
- Python 3.9 أو أعلى
- pip (مدير حزم Python)

### 1. **استنساخ المستودع**
```bash
git clone https://github.com/ahmedalmnaweer-ui/Smart-HSA-HQ-.git
cd Smart-HSA-HQ-
```

### 2. **إنشاء بيئة افتراضية (اختياري لكن موصى به)**
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. **تثبيت المتطلبات**
```bash
pip install -r requirements.txt
```

### 4. **تشغيل التطبيق**
```bash
streamlit run Smart-HSA-HQ-app.py
```

### 5. **فتح التطبيق**
سيفتح التطبيق تلقائياً في المتصفح على:
```
http://localhost:8501
```

## 🔧 دليل الاستخدام التفصيلي

### **الخطوة 1: استيراد البيانات** 📂
1. افتح التطبيق واذهب إلى قسم **الرئيسية** 🏠
2. اختر ملف Excel يحتوي على البيانات المطلوبة
3. اضغط على **استيراد ملف الإكسل الآن**
4. سيتم معالجة البيانات تلقائياً

### **الخطوة 2: عرض النتائج** 📊
- انتقل إلى **التكلفة التقديرية**
- ستظهر جميع البنود المستوردة
- اختر البنود المراد احتسابها

### **الخطوة 3: حساب التكاليف** 🧮
- اضغط على **احسب التكلفة التقديرية**
- سيظهر الإجمالي والتفاصيل الكاملة
- عرض رسوم بيانية التوزيع
